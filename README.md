# Kosakata Video

Unggah video, lalu aplikasi akan mentranskripsi ucapannya (Whisper, berjalan di browser) dan menampilkan setiap kosakata beserta artinya di layar tepat saat kata itu diucapkan.

**Buka aplikasinya:** https://yohana-gif88.github.io/kosakata-video/

Fitur: daftar kosakata dengan arti dan jenis kata, transkrip + terjemahan kalimat, unduh CSV, dan unduh video dengan subtitle kosakata. Gunakan Chrome atau Edge terbaru.
